# Python for REST APIs — From Zero to Production

A hands-on course for complete beginners who want to build web services (REST APIs) with Python — and learn the professional workflow around them: Git, GitHub, Pull Requests, testing, Docker and CI/CD.

This course was written while actually learning, so every lesson includes the real errors a beginner runs into and how to fix them.

## How this course works

- **Learn by building.** Each lesson is a short concept followed by code you type yourself (don't copy-paste — typing builds muscle memory).
- **Git from day one.** Every exercise is committed on a branch and merged through a Pull Request, just like on a real team.
- **Small and steady.** About 6–8 hours a week: short sessions on weekdays, longer builds on weekends.

## Course map

| Phase | Weeks | Topics | Project |
|---|---|---|---|
| 0. Setup | 1 | Terminal, Git, GitHub, SSH, uv, VS Code | First repo and first Pull Request |
| 1. Core Python | 1–4 | Variables, types, control flow, functions, data structures, files, errors, modules | Command-line to-do app |
| 2. Intermediate Python | 5–7 | OOP, dataclasses, type hints, comprehensions, decorators, pytest, calling APIs | Weather CLI using a public API |
| 3. How the web works | 8 | HTTP methods, status codes, headers, JSON, REST, curl | Exploring real APIs |
| 4. REST APIs with FastAPI | 9–12 | Routing, Pydantic, CRUD, databases, auth (JWT), async, testing | Task/Bookstore API |
| 5. Production | 13–16 | Docker, docker compose, config, logging, GitHub Actions CI/CD, deployment | Deployed, auto-tested API |
| 6. Kubernetes (optional) | 17–20 | Local clusters, Deployments, Services, ConfigMaps, Helm | API running on Kubernetes |
